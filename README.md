# BuscaRepuestos.cl — Landing de Distribuidores

Landing B2B para captación de distribuidores de repuestos automotrices.

## 🚀 Quick start

```bash
# Instalar dependencias
npm install

# Compilar Tailwind (genera public/css/styles.css)
npm run build:css

# Levantar servidor local en http://localhost:3000
npm run serve
